# LLM BioBenchmarking

This project aims to benchmark bioinformatics workflows generated by large language models against standardized, containerized reference components.

The goal is to evaluate whether LLM-produced workflows use appropriate, current, reproducible, and efficient tools for common bioinformatics tasks.

## Prospective Tasks

- Genome assembly
- Multiple sequence alignment
- Phylogenetic tree construction
- Feature annotation
- Taxonomic assignment
- FASTQ quality assessment and preprocessing
- SNP analysis
- RNA-seq analysis
- DNA methylation analysis
- Bacterial genome annotation
- Bioinformatics data retrieval
- Phylogenetic placement

Each task should define reference inputs, expected outputs, container requirements, evaluation metrics, and resource-use measurements.
